# 진담 중국어 오락실

진담중국어 게임을 한곳에 모아 아이들이 골라서 할 수 있는 페이지예요.

- `index.html` 한 장짜리 페이지 (빌드 없음)
- 게임 카드는 각 게임의 원래 주소로 연결돼요 (아이들 기록이 그대로 이어지게)
- 새 게임을 추가할 때는 `index.html` 아래쪽 `CATS` 목록의 알맞은 묶음에 한 줄(이름·주소·아이콘·태그·설명)을 추가하고, 아이콘은 `icons/`에 넣어요
- 묶음: 초등 친구들 / 한자 쓰기 / HSK 단어 게임
